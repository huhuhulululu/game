# 并肩山谷

两个人、两部 iPhone，进同一座活着的山谷。

钓鱼、下矿、打造、做菜、种田、问今日之运，都开着。没有人规定今晚的高潮在厨房还是在河边。

设计说明见 [docs/WORLD.md](docs/WORLD.md)。

## 两部手机怎么玩

1. 电脑上启动：`npm install && npm run dev`
2. 两部 iPhone 打开同一个地址（同一 Wi-Fi 下用电脑的局域网 IP，例如 `http://192.168.1.8:5173`）
3. 一人点「开一间」，把四位房间码给对方
4. 另一人输入同一个码，点「进去」
5. Safari 里可以「添加到主屏幕」，会更像 App

左摇杆移动，右下「做」互动 / 攻击 / 起竿，「喊」让对方屏幕闪一句你在哪。

电脑调试：WASD 或方向键，空格做，H 喊。

## 山谷里有什么

- **河**：下竿、等咬、起竿。鱼有重量和品质（普通 / 厚实 / 沉重），规则借自饥荒联机的海鱼秤。两人同时钓，才可能出银鳞。
- **矿**：每层随机遭遇。掉落用我的世界那套战利品表，装备用暗黑的前缀后缀。
- **工坊**：粗矿和青木打成带词缀的刃。
- **厨房**：饥荒锅。最多四样食材，按肉/鱼/菜/蛋/甜的标签匹配菜单；对不上就是「一锅糊涂」。煮出过的菜会写进菜单。
- **田**：种下去就走，不用浇水。下雨或分头时长得快一点。
- **荒野**：山谷东边出谷。地图先是黑的，走过去才亮。夜里没火会被黑暗咬一口。残骸、篝火、洞，都在路上。
- **厨房堂口**：客人堆上来才会变成 Overcooked 式催菜；平时就是饥荒那口锅。
- **卦棚**：两部手机都按过「问今日」，才揭签。
