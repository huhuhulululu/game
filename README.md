# 并肩山谷

两个人、两部 iPhone，进同一座活着的山谷。

钓鱼、下矿、打造、做菜、种田、问今日之运，都开着。没有人规定今晚的高潮在厨房还是在河边。

设计说明见 [docs/WORLD.md](docs/WORLD.md)。

## 两部手机怎么玩

1. 电脑上启动：`npm install && npm run dev`
2. 两部 iPhone 打开同一个地址（同一 Wi-Fi 下用电脑的局域网 IP，例如 `http://192.168.1.8:5173`）
3. 一人点「开一间」，进谷后把屏幕上的四位房间码给对方
4. 另一人输入同一个码，点「进去」（码不存在会提示没有这间山谷）
5. Safari 里可以「添加到主屏幕」，会更像 App

左摇杆移动，右下「做」互动 / 攻击 / 起竿，「喊」让对方屏幕闪一句你在哪。信号断了人还在原地，同一房间码再进会坐回原来的位子。

电脑调试：WASD 或方向键，空格做，H 喊。

## 山谷里有什么

- **河**：下竿、等咬、起竿，然后要在绿段里按「做」把鱼拉上来。鱼有重量和品质。两人同时把竿子放进同一片水（山谷或出谷的岸），才可能出银鳞。出谷的岸边还能钓到鲈和鳅。点「菜单」能看见鱼册和菜册凑了多少。
- **矿**：每层随机遭遇。矿脉层矿石更多、挖也更肥。两个人都在矿里会听见彼此的脚步。掉落用我的世界那套战利品表，装备用暗黑的前缀后缀。
- **工坊**：对着砧花粗矿和青木开炉。标在绿段时按「做」，打三下。两个人都面对砧、同一窗口打中绿，才出成对的刃。一个人或对方断线就是单人结果；一次都没打中会卷刃。
- **摊位**：每天 2–3 样。面对摊按「做」看货，绿的时候再按。单人能买种子、燧石这些今晚用得上的。两个人对着同一件点中绿，才拿得到今日成对的戒或更好的一样。没点中绿，定金没了，货还在。
- **厨房**：饥荒锅。最多四样食材，按肉/鱼/菜/蛋/甜的标签匹配菜单；对不上就是「一锅糊涂」。煮出过的菜会写进菜单。
- **田**：种下去就走，不用浇水。下雨或分头时长得快一点。熟了能看见要收什么；偶尔会长出异株。
- **歇一夜**：两个人都在时，都要在屋里躺下，夜才过。夜里靠着火坐一会儿，饿得慢。雨会浇灭荒野的篝火。
- **荒野**：山谷东边出谷。饥荒式探险是户外主循环：地图先是黑的，走过去才亮；林、沼、荒草、石丘各有东西可砍、可砸、可翻。夜里没火会被黑暗咬一口。砸出燧石，和木、草对着燃着的篝火能搓火把；对着旺火还能把生肉、鱼、蛋烤熟。旧营能搜一次，两人一起翻更好。走路会偶尔脚下绊到草、石、种子。春夏秋冬会转。两人走近，看见的路会写进彼此的图。点「图」能看到已照亮的岛。手里有吃的、面对空地，按「做」就是吃。
- **厨房堂口**：Overcooked 只出现在这里。客人堆上来才会催菜：对单才收、炉子会糊、两个人得传菜（催菜时递得更远）。短时间连着上菜会「连上了」。中间有冰柜，鱼和肉放进去会慢点坏。平时就是饥荒那口锅。荒野不按 Overcooked 跑。
- **腐坏**：鱼、肉、菜会从鲜到蔫再到坏。坏了变成一锅糊涂。夏天更快，冰柜更慢。手里有吃的对着空地按「做」就是吃。
- **卦棚**：两部手机都按过「问今日」，才揭签。旁边看板在睡过一夜后挂今晚要做的菜，两个人揭开后进厨房，单已经在。
- **查理**：村里的田和路夜里有灯。没火没火把会被咬的，是荒野和出谷门口。
