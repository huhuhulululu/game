# 并肩山谷 · 一套语言

对照 `cover-valley.png`。封面是锁，不改。谷、厨、矿、荒野、HUD 都吃这口气。  
公开仓库的 MIT / 课是结构：一套作者、同一比例、统一脚影、一层空气。不抄他们的图，不另下三套包。

## 锁

- **色温：** 暖黄昏。天是橙粉，影是暖褐，不是冷蓝、不是紫夜。谷白天 `Look.VALLEY_DUSK = Color(1.14, 0.78, 0.52)`。夜仍暖暗 `(0.78, 0.68, 0.52)`。荒野没火 `(0.46, 0.38, 0.28)`。厨 / 矿墙面保持 `(1, 1, 1)`，空气仍是这一层。
- **主光：** 西 / 左。太阳在封面左脊。高光在物的左侧，脚影偏东 / 右。`Look.SHADOW_EAST`。不要顶光、不要第二轮太阳。
- **描边：** 无硬墨线。软边插画。形靠色和光，不靠黑圈。禁止饥荒笔触、禁止像素描边。
- **脚影：** 同一套软椭圆接地影，偏东。人、屋、树、摊同一规则。不要每件道具自带另一种影子。
- **禁止混包：** 人和屋和地来自同一支笔、同一套比例。北脊只用 `prop-tree` / `prop-tree-wide`。玩区屋只用 `prop-hut` / `prop-lodge`（封面那两座，经 `unify_dusk`）。不要 `prop-pine`、不要 `prop-tree-gold`、不要红顶像素屋、不要另一套小人。

## 这一套是什么

软边、日常衣褶的一对人（暖 = 驼大衣；松 = 橄榄夹克）。屋是封面那两座木头房子，窗里暖黄。树是成团的叶子，西边金、东边深橄榄。地是一条土路、一条溪，短湿土唇。

HUD 也是这个世界的木头：`tex-slip` / `tex-plaque` 从 `prop-cabin` 的木纹 + `tex-paper` 钉上去。不要圆角米色表单框，不要第二套 UI 皮。

## 可以有、不要叠

一层很轻的全屏空气：暖暗角 + 细颗粒。`shaders/air.gdshader`。收成同一种空气，不是新风格，不是海滩天气插件。不要再叠第二层调色。`dusk.gdshader` 的 `grade` 保持 `0.0`。

## 宁肯少

少一件道具，胜过第二种语言。远景近景同一支笔。封面写实、谷里不要像素屋、不要墨线浆果丛、不要贴纸摊。

课是结构。素材是我们自己的山谷。
