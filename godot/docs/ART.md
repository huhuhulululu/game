# 并肩山谷 · 一套语言

对照 `cover-valley.png`。封面是锁，不改。谷、厨、矿、荒野、HUD 都吃这口气。  
公开仓库的 MIT / 课是结构：一套作者、同一比例、统一脚影、一层空气。不抄他们的图，不另下三套包。

## 锁

- **色温：** 暖黄昏。天是橙粉，影是暖褐，不是冷蓝、不是紫夜。地本身就是封面那口橄榄金，不是绿场再套一层橙色滤镜。谷白天 `Look.VALLEY_DUSK = Color(1.0, 1.0, 1.0)`，HUD 写白天也不再乘一层橙。夜仍暖暗 `(0.78, 0.68, 0.52)`。荒野没火 `(0.46, 0.38, 0.28)`。厨 / 矿墙面保持 `(1, 1, 1)`。夜打在床上，画里已有的灯还是灯，不要整屏紫滤镜，不要另贴一盏灯。
- **主光：** 西 / 左。太阳在封面左脊。高光在物的左侧，脚影偏东 / 右。`Look.SHADOW_EAST`。不要顶光、不要第二轮太阳。
- **描边：** 无硬墨线。软边插画。形靠色和光，不靠黑圈。禁止饥荒笔触、禁止像素描边。
- **脚影：** 同一套软椭圆接地影，偏东。人、屋同一规则。不要每件道具自带另一种影子。
- **禁止混包：** 人和屋和地来自封面同一支笔、同一套比例。玩区谷是一张画：`bed-valley.png` 坐在 `valley.tscn` 里，屋、树、灯、岸画在床上，不要再把封面裁成 `prop-cover-*` / `prop-hut` / `prop-lodge` 往回贴。进谷镜头里要看得见树和两座屋——在那张画里，不是贴纸。不要 Wanderer 客栈、不要 `prop-pine`、不要 `prop-tree-gold`、不要红顶像素屋、不要另一套小人、不要像素球树。

## 这一套是什么

软边、日常衣褶的一对人（暖 = 驼大衣；松 = 橄榄夹克）。大衣真透明，图外是 a=0，不是黑底方块。`Look.BODY = 240`，坐在路上像画里的人，不是 40 像素小精灵，也不是贴在床上的小章。镜头跟着大衣走在路上，不要整张床当邮票底。脚下同一口偏东软影，人在路上，不是悬空章。大衣吃一口暖褐金 grade，同一张脸，不是冷键动漫章，不另造人。走路是现有 walk / walk2 / 站立四拍，不是两张章对打。暖的走是同一件驼大衣迈步，不是滑章。暖的坐是同一件驼大衣的坐，糊了就留下现有的坐，不另造一张脸。屋是封面那两座木头房子，窗里暖黄，脚在床的土里，不要贴纸方框。地是一条土路、一条溪，橄榄金黄昏，和屋同一张床。厨 / 矿 / 荒野也是同一张黄昏画，不是空填、不是拼贴。活人不画进床。HUD 没有魂，没有精神值，牌上不写一条饿的数字。袋是一行木签，牌下一小块木签，不要一条长木条横贯画面，不要八个一样的木框。

HUD 也是这个世界的木头：`tex-slip` / `tex-plaque` 从 `prop-cabin` 的木纹 + `tex-paper` 钉上去。不要圆角米色表单框，不要第二套 UI 皮。不要饥荒背包条。进谷只见封面那张画，不要 DOM 标题字叠在画布底下。右上角没有空木框。开一间的牌是黄昏木头，不是羊皮纸表单。房间码的牌也是同一块黄昏木头。谷里的做喊声是小木签，不是三块一样的框。网页点路能走，键盘 WASD 能走，做喊还是那三块小木签，不要饥荒摇杆圈。做到画上的门就进厨进矿，不要另贴一扇门。做到溪上就下竿，做到谷口就出谷，不要另贴竿和门。做到锅上就入锅，做到矿脉就挖，不要另贴锅和镐。底下没有空木条。有字才出一小块木签。自己头上没有木框名牌。自己头上没有名牌。对面是一行淡墨。

## 可以有、不要叠

一层很轻的全屏空气：细颗粒，不要橙色罩。`shaders/air.gdshader`。不要再叠第二层调色。`dusk.gdshader` 的 `grade` 保持 `0.0`。床不吃橙色罩。大衣的暖口只在 `person_mat` 上。

## 宁肯少

少一件道具，胜过第二种语言。宁肯少几棵封面大树，也不要摊、砧、像素球树。远景近景同一支笔。

课是结构。素材是我们自己的山谷。
