# 《并肩山谷》在做什么

给两个人、两部 iPhone 的一个活世界。  
不是三个小游戏，也不是一条必须走到「晚上开店」的高潮轨道。

## 参考顺序（按你们喜欢的程度，不要搅）

1. **饥荒 / Don't Starve Together（最大，整座游戏）**  
   不是只借一口锅。探险、地图先黑、夜里没火、分头或并肩、地上捡回来的东西进锅——整座山谷按这个骨头长。你们喜欢饥荒的整款游戏，尤其是出营地往外走的那一段。
2. **星露谷物语**  
   一座谷里有很多地方可以待。不规定今晚该去哪。不做成每天浇水、每天同一套日常。
3. **潜水员戴夫**  
   在世界里捞到的东西，可以进锅。不是「白天铺垫、晚上才是正餐」。
4. **Overcooked（只进个别场景）**  
   整座游戏不是 Overcooked。它只放在厨房「堂口热起来」的那一段：传菜、催单、两个人手忙脚乱。荒野、河、矿都不按 Overcooked 跑。以后若再借它，也只是某个具体场景，不扩散成主循环。

我们自己的游戏和上面任何一款都不一样。参考是骨头，不是换皮。

## 已经定下的事

- 骨头按上面的顺序长，不把四款游戏搅成一锅。
- **两部 iPhone**，各看各的屏幕，各控一个人，进同一间山谷。
- **没有签到**。改成「今日两人之运」：抽签 / 算卦 / 运势，读起来像你们的生活，也会轻轻偏一下今天的随机。
- **不标注高潮**。钓鱼磨技术、下矿打遭遇、做新菜等客人、出谷把地图一点点填亮，都是完整玩法。今晚只钓鱼，也算把这晚过完。
- **不要精神值**。夜里的压力就是黑暗会咬、火要添、林子里会跟来东西。不再加一条「神」。

## 世界怎么活

同一座山谷里，这些地方一直开着：

| 地方 | 一个人可以在这里一直玩的东西 | 随机 |
| --- | --- | --- |
| 河 | 钓鱼手感、鱼种图鉴、饵和钓点 | 鱼、尺寸、旧靴、水底匣、双人同钓才出的银鳞 |
| 矿 | 多层、打怪、 ident 怪物图鉴 | 遭遇（空房 / 伏击 / 精英 / 矿脉 / 神龛）、爆率、词缀 |
| 工坊 | 把矿和木头打成装备 | 品质、词缀、成对武器要两把都在才觉醒 |
| 厨房 | 配方、手法、客人 | 点菜、小费、客人顺手留下的种子或菜谱 |
| 田 | 种下去就走，不用浇水。熟了能看见要收什么 | 收成数量、偶发异株 |
| 卦棚 | 两个人一起问今日 | 签文本身；并轻微改河/矿/店的表 |
| 荒野 | 饥荒式探险：地图先黑、走过去才亮；林、沼、荒草、石丘；春夏秋冬会转。燃着的篝火能烤生食；旧营能搜一次 | 残骸、旧营、篝火、虫洞、丝巢、夜里的黑暗、燧石火把、探路时脚下绊到的草和石 |

一个人在河边磨钓，另一个在矿里清层，都成立。  
一个人出谷探路，另一个在厨房守锅，也成立。  
背包、冰箱、金币是共用的。你钓上来的鱼、砍下来的木，对方可以直接拿去下锅、添火。

两个人的影响是世界规则，不是任务：

- 离得近：经验平分、暴击和爆率好一点，成对装备会热；荒野里看见的路会写进彼此的图。
- 分头：田长得快一点，店里客人更杂，河和矿各滚各的表。
- 银鳞：两个人同时把竿子放在水里，才肯咬。
- 今日之运：两部手机都按过「问」，才揭签。签文先是生活口吻，再是今天的偏置（宜近水、宜同路、宜分头、宜入厨……）。

没有人会在屏幕上写「今晚请去开店」。灯自己亮着，你去不去是你的事。

## 两部 iPhone

- 一人一机，摇杆在左，动作在右。不必横屏挤两个人。
- 一人开间，出房间码；另一人输入同一个码。断线的人停在原地，同一名字或同一边再进，坐回原来的位子。空房间会留十分钟。
- 镜头跟着自己。对方在别的地方时，只看到「她在河边」或「她在沼地那边」。
- 对方钓到稀的、打造出锋刃、客人留下一张方子，两部手机都会闪一句。

## 借用的公开规则（不抄素材，只抄算法）

- **掉落**：我的世界战利品表（pools / rolls / bonus_rolls×运气 / weight / empty）。见 [Loot table](https://minecraft.wiki/w/Loot_table)。
- **装备**：暗黑 II 的品质管线（unique/rare/magic/normal）+ 前缀/后缀、同组不叠。见公开的 item generation 笔记。
- **天气**：星露谷式权重表（晴、雨、雷雨、雾、风），雨偏钓鱼，雷雨偏矿。
- **做饭**：饥荒锅。四种食材、标签加总（肉/鱼/菜/蛋/甜/填料）、优先级最高的菜胜出，对不上就是「一锅糊涂」。菜单靠自己煮出来，像 DST 的 Cookbook。[Crock Pot](https://dontstarve.wiki.gg/wiki/Crock_Pot) / [Food Value](https://dontstarve.wiki.gg/wiki/Food_Value)。
- **鱼品质**：饥荒联机版海鱼重量 `rand*(max-min)+min`，过了区间 70% 算沉重。[Weight](https://dontstarve.wiki.gg/wiki/Weight)。沉重的鱼在锅里的鱼值和肉值更高。
- **探险**：饥荒地图先是黑的，走近才填上；夜里没火会挨咬（查理只在地面，矿里有灯）；地上有路、残骸、篝火、洞、林沼石丘。[Map/DST](https://dontstarve.wiki.gg/wiki/Map/DST)。两人走近，当前看见的格子会写进对方的图。春夏秋冬每三天一转，冬天夜来得早、火烧得快。燧石+木+草能搓火把。
- **腐坏**：鱼、肉、菜会蔫、会坏，坏了变成「一锅糊涂」。夏天坏得快，冬天慢。厨房冰柜能把腐坏压到很慢，像饥荒的 Ice Box。蔫了的食材进锅，标签会打折。
- **堂口**：客人堆到两单以上，厨房才进入 Overcooked 式催菜：传菜、对单、炉子会糊。催菜时传菜距离更远；短时间连着上菜会「连上了」，多给一点金。平时仍是饥荒那口锅。山谷和荒野不借用 Overcooked。
- **营火**：对着燃着的篝火，手里的生肉、鱼、蛋、麦可以烤熟，像饥荒的营火、戴夫把捞上来的东西就地处理。烤过的更好吃，也能直接进锅。
- **探路**：荒野里每照亮一片，有机会脚下绊到山草、燧石或种子。不是任务，只是走路本身会给东西。
- **喊**：按「喊」，对方屏幕上那个人会冒一圈光，小地图上也会亮一下。
- **歇一夜**：两部手机都在时，两个人都要在屋里躺下，夜才过。一个人进山谷，可以自己歇。
- **火边**：夜里两个人都靠着燃着的篝火或屋里的灯，坐一会儿饿得慢，默契会加一点。不是任务，火在就可以坐。
- **雨**：雨和雷雨会把荒野的篝火浇灭，要重新添。
- **矿脉**：这一层矿脉很响的时候，矿石更多，挖也会多掏出一块。两个人离得近，爆率好一点。

## 明确不做

- 每天浇水、每天同一套日常才能进步。
- 用主线把人推进厨房当高潮。
- 把整座游戏做成 Overcooked，或把催菜扩散到荒野。
- 普通手游签到（连三日领金币）。
- 一部手机左右劈开两套操作。
