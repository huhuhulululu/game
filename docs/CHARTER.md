# 《并肩山谷》立项

两个人、两部 iPhone，过同一个晚上。  
这是一款**大型双人晚间游戏**。终点是 **iOS App Store**。

设计细账在 [WORLD.md](WORLD.md)。这份只钉产品：它是什么、现在做到哪、骨头按什么长、什么现在不做。

## 它是什么

同一座活着的山谷。一人一机，各看各的屏幕，进同一间。  
钓鱼、下矿、打造、做菜、种田、问今日之运、出谷探路，都开着。没有人规定今晚的高潮在厨房还是在河边。

**独特层是并肩。** 两个人必须互相影响才算这款游戏：同钓、同砧、同摊、传菜、一起揭签、一起躺下过夜。一个人也能把一晚过完，但成对的东西要两个人才肯来。

**没有精神值。** 夜里的压力就是黑暗会咬、火要添、林子里会跟来东西。不再加一条「神」。

## 骨头顺序（不要搅）

按喜欢的程度长，不是四款游戏煮一锅：

1. **饥荒 / Don't Starve Together（最大，整座户外）**  
   探险、地图先黑、夜里没火、地上捡回来的东西进锅。整座山谷按这个骨头长。
2. **星露谷物语**  
   一座谷里地方多，可以待。不做成每天浇水、每天同一套日常。
3. **潜水员戴夫**  
   白天捞到的，晚上进锅。不是「白天铺垫、晚上才是正餐」。
4. **Overcooked（只进厨房堂口）**  
   整座游戏不是 Overcooked。只放在「堂口热起来」：传菜、催单、炉会糊。荒野、河、矿都不按它跑。

参考是骨头，不是换皮。我们自己的游戏和上面任何一款都不一样。

## 现在不做

- **今晚不封包。** 还在 P0。网页这一晚先好看、能玩。
- **不加精神值。**
- **不把 Overcooked 铺到荒野。** 催菜只留在厨房堂口。
- 不把主线推进厨房当高潮。
- 不做每天浇水、每天同一套日常。
- 不做普通手游签到。
- 不把一部手机左右劈开两套操作。
